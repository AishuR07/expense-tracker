# 💰 Expense Tracker

A simple **Expense Tracker** built using **Python and SQLite** to manage income and expenses.

## ✨ Features

- Add income and expenses
- View transactions
- Update and delete transactions
- Calculate total income, expenses, and balance
- Store data using SQLite

## 🛠️ Technologies

- Python
- SQLite
- SQL
- Git & GitHub

## 📂 Files

```text
expense-tracker/

```

## ▶️ Run

```bash
python main.py
```

The database is created automatically when the program runs.
